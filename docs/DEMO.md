# 三分钟演示流程

[返回项目首页](../README.md) · [使用教程](USER_GUIDE.md)

这份流程用于介绍当前实际可运行的浏览器版本。以下时间分配是建议，不是识别速度或性能测量结果。

## 演示前准备

- 使用已验证能打开的浏览器和网址；网络不稳定时准备本地 localhost 版本。
- 调整光线与摄像头位置，让手部完整可见；提前确认权限可以正常申请。
- 关闭占用摄像头的程序，检查画面状态和当前帧率；必要时降低数量或关闭后处理。
- 准备一段实际操作录屏，保留按钮作为识别失败时的替代路径。
- 当前未接入硬件设备，演示过程中应按浏览器原型说明能力。

## 0:00–0:25：说明体验目标

> 这是手势粒子宇宙。我希望把抽象的三维参数变成容易理解的动作，让第一次打开的人也能用身体动作改变数字空间。页面可以直接在浏览器中运行。

展示默认球体和右侧控制面板。

## 0:25–1:20：完成单手与双手交互

1. 开启摄像头，指向预览和手部关键点。
2. 展开手掌，再握拳，展示扩散与收缩。
3. 左右移动手掌，展示旋转。
4. 同时展示双手，拉开并靠近，展示相对缩放。
5. 伸出食指，展示局部漩涡。

> 稳定机制会过滤短暂误识别，并对参数进行平滑处理，避免关键点轻微抖动直接变成画面跳动。

若识别不稳定，说明光照和遮挡是当前限制，直接切换屏幕按钮继续演示。

## 1:20–2:00：展示形态和替代操作

切换银河、无限符号和爱心；再演示两种配色、鼠标交互和重置。比心成功时说明它是几何规则识别；未成功时直接点击爱心。

> 六种形态共享一组粒子数据结构，在 GPU 中插值过渡。没有摄像头也能通过鼠标、触屏或按钮操作。

## 2:00–2:35：说明实现与隐私

> 感知使用 MediaPipe 预训练模型；自定义部分是手势映射、稳定处理、粒子分布和 Shader。识别优先在 Worker 中运行，画面独立渲染。应用不保存或上传摄像头画面，用户可以随时关闭摄像头。

可打开 README 中的架构图，说明 CPU、Worker 与 GPU 分别承担什么工作。

## 2:35–3:00：说明边界和下一步

> 当前已经实现浏览器中的完整交互流程；真人准确率、不同设备性能和硬件联动需要继续验证。下一步考虑把手势参数与实体交互装置连接起来，并用实测数据评估稳定性和响应速度。

结束演示并关闭摄像头。

## 演示录像建议

建议包含真实操作与实际页面的对应关系，而不仅是粒子画面。可以拍到操作者双手与屏幕，或在授权范围内录制预览区域；发布前检查是否包含人脸、账户或其他个人信息。

录像依次展示：启动画面 → 摄像头授权 → 开掌 / 握拳 → 双手缩放 → 食指漩涡 → 多形态 → 手机操作 → 关闭摄像头。

## 常见提问

**是否训练了新模型？** 没有，使用 MediaPipe 官方预训练模型，在关键点之上实现自定义交互规则。

**是否已经支持 RDK 或机器人？** 尚未接入，当前是浏览器原型，扩展计划见 ROADMAP。

**能否保证 60 FPS 或稳定识别所有人的手势？** 当前没有跨设备基准和真人准确率实验，不能作此承诺。可以展示演示设备上的实时读数，并明确设备与环境。

**AI 辅助了哪些工作？** 使用 Codex 辅助生成和修改代码、文档及开发检查；需要由项目维护者继续完成真机验证与结果复核。
